Detailed Description

template<typename Derived>
class helios::mem::AtomicRefCounted< Derived >

Atomic PMR intrusive reference-counted handle.

The memory resource is part of the handle state and is propagated by every copy, move, and assignment. Separate handles may be released safely on different threads.

Warning
The managed type must inherit from ArcFromThis<Derived>.
