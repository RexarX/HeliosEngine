◆ Probe()

bool helios::sdl3::Probe ( SDL_InitFlags flags)
nodiscard

Tests whether a subsystem can be initialized, then fully tears it down when this process has no outstanding Retain.

Uses SDL_Init/SDL_Quit so X11/XKB resources from a probe do not leak into LeakSanitizer at process exit. Safe to call after Retain: the live session is left intact.

Parameters
flagsSubsystem flags to probe
Returns
True if the subsystem initialized successfully
