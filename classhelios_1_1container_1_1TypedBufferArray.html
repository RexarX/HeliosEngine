Detailed Description

Type-erased sequential byte storage for a single type (array variant).

Stores multiple instances of a type in a contiguous std::pmr::vector<std::byte> buffer. The stored type is not fixed at class instantiation but is verified at runtime. Object lifetimes are properly managed. Trivially-copyable types are fast-pathed.
