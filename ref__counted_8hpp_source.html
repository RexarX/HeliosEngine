615 * @warning Triggers an assertion when `resource` is null.
616 * @tparam T Object type
617 * @tparam Args Constructor argument types

619 * @param args Arguments forwarded to the object constructor
620 * @return Owning handle with reference count one
621 */

624 std::constructible_from<T, Args...>
