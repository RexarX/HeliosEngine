Detailed Description

Per-system registry for tracking consumed message ids.

Each system running in parallel gets its own ConsumedMessagesRegistry instance. Systems mark messages as consumed by writing stable message ids into their registry, avoiding data races. At Update time, all registries are merged and applied to message queues in MessageManager.

Entries are monotonic message ids assigned when messages enter the global manager — not transient indices into the previous/current buffers.

Note
Not therad-safe.
