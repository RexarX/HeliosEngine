Detailed Description

template<MessageTrait T>
struct helios::ecs::MessageId< T >

Monotonic identity for a buffered message of type T.

Assigned when a message enters the global MessageManager (direct write or local-queue merge). Identities survive buffer aging and are stable under consumable-message removal.
