Detailed Description

Type-erased, type-checked message identity.

Stored in MessageManager and ConsumedMessagesRegistry containers. Carries the originating MessageTypeIndex so As<T>() / TryAs<T>() can recover a typed MessageId<T> safely at API boundaries.
