Detailed Description

template<MessageTrait T>
class helios::ecs::BasicMessageWriter< T >

Type-safe writer for regular messages.

Messages written through BasicMessageWriter are buffered in a message queue and merged into the global MessageManager at sync time when used from system local data. Ids are assigned during that merge.

Note
Not thread-safe.
