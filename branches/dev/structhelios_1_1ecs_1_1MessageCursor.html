Detailed Description

template<MessageTrait T>
struct helios::ecs::MessageCursor< T >

Per-reader cursor tracking which messages of type T have been seen.

Retention (previous/current buffers) and delivery (this cursor) are independent. Two systems each keep their own cursor and can both observe the same retained message once. Store via Local / SystemLocalData for system parameters; pass explicitly to World::ReadMessages.
