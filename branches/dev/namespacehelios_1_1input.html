float helios::input::ApplyLinearDeadzone ( float value,
float deadzone,
float livezone,
bool rescale )
nodiscardconstexprnoexcept

Applies a 1D deadzone and optional rescale.

Values with magnitude below deadzone become 0. Magnitudes at or above livezone saturate to +/- 1 when rescale is set, otherwise to +/- livezone. Between the two, rescale maps the remaining range onto [0, 1] (preserving sign).

Parameters
valueAxis value, typically in [-1, 1] or [0, 1]
deadzoneInner cutoff (exclusive)
livezoneOuter saturate magnitude
rescaleRemap (deadzone, livezone) onto (0, 1)
Returns
Filtered value

◆ ApplyRadialDeadzone() [2/2]

auto helios::input::ApplyRadialDeadzone ( float x,
float y,
float deadzone,
float livezone,
bool rescale ) -> std::pair< float, float >
nodiscardconstexpr

Applies a circular (radial) deadzone to a stick pair.

If the vector length is below deadzone, returns (0, 0). At or above livezone, rescale saturates onto the unit circle; otherwise the vector is scaled to length livezone. Between the two, rescale maps length onto (0, 1] along the same direction.

Note
When livezone <= deadzone, the whole range is treated as dead.
Parameters
xX component
yY component
deadzoneInner radial cutoff
livezoneOuter radial saturate length
rescaleRemap (deadzone, livezone) onto (0, 1]
Returns
Filtered (x, y) pair
