8/**
9 * @brief Lock-free intrusive Treiber stack.
10 * @details Nodes are untyped `void*` values. The first `sizeof(void*)` bytes of
11 * each node store the successor pointer and are accessed with
12 * `std::atomic_ref`. The stack head is a 128-bit `{pointer, tag}` word so the
13 * ABA tag is a full native integer and does not wrap after 65536 operations.
14 *
15 * The stack never allocates or frees nodes. Callers own node storage for the
16 * lifetime of every pointer currently in the stack.
17 *
18 * @note `Push` and `Pop` are safe to call concurrently. `Clear` and move
19 * operations require exclusive access.
20 *
21 * @code
22 * struct Node {
23 * Node* next = nullptr;
24 * int value = 0;
25 * };
26 *
27 * helios::mem::TreiberStack stack;
28 * Node a{.value = 1};
29 * Node b{.value = 2};
30 * stack.Push(&a);
31 * stack.Push(&b);
32 * Node* top = static_cast<Node*>(stack.Pop());
33 * @endcode
34 */
