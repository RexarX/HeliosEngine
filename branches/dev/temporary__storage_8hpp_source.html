8/**
9 * @brief Per-thread bump allocator for frame and task-scoped allocations.
10 * Same idea as Jai's `Temporary_Storage`.
11 * @details Any thread that calls `Instance()` (job workers, third-party
12 * threads, test threads) lazily claims one slot from a fixed-size pool on
13 * first use. No setup call is required. The hot allocation path is a private
14 * bump pointer with no atomics: once a slot is claimed, no other thread
15 * allocates from it.
16 *
17 * The `thread_local` destructor never calls malloc/free/new/delete. It only
18 * CAS-es slot state (`kActive` -> `kRetired`, or `kBusy` -> `kBusyRetired` if
19 * `ResetAll()` currently holds the slot). Memory a retired slot holds is
20 * released lazily by whichever thread later claims that slot, never by the
21 * exiting thread.
22 *
23 * @warning `Reset()` / `ResetAll()` invalidate every pointer previously
24 * handed out by the affected resource(s). Only call them at a point where
25 * nothing still holds a temporary allocation (e.g. end of frame, full
26 * barrier).
27 */
28class TemporaryStorage {
29public:
30 static constexpr size_t kInitialBlockSize = 4UZ * (1U << 10U); // 4 KB
31 static constexpr size_t kMaxThreads = 256;

45
46 /**
47 * @brief Rewind this thread's own storage.
48 * @warning Invalidates prior allocations made on this thread only.
49 */
50 static void Reset() noexcept;
51
52 /**
53 * @brief Rewind every currently live thread's storage.
54 * @details Concurrent `Instance()` / allocate on another thread is a
55 * caller error (frame-barrier contract). Thread exit concurrent with
56 * this call is handled: a dying thread never frees. `ResetAll()` keeps
57 * the slot `kBusy` for the duration of `release()` so it cannot be
58 * reclaimed mid-reset; if the owner left, the restoring CAS fails and
59 * the slot is published as `kRetired`.
60 * @warning Invalidates all outstanding allocations on every live slot
61 * this call successfully claims.
62 */
63 static void ResetAll() noexcept;
64
