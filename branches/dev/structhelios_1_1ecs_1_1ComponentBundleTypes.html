Detailed Description

template<typename... Ts>
struct helios::ecs::ComponentBundleTypes< Ts >

Component and nested-bundle values for a bundle operation.

Lists component types and/or nested bundle types at compile time. Nested types are flattened depth-first, left-to-right, for add/remove. The same type also stores leaf and nested bundle values in declaration order.

Template Parameters
TsComponent types and/or nested bundle types
