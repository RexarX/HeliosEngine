22/**
23 * @brief Sleeps for `duration` with SDL_DelayPrecise-style accuracy.
24 * @details Sleeps in ~1 ms chunks while tracking scheduler overshoot, then
25 * busy-waits the remainder with a CPU pause. Zero or negative durations
26 * return immediately.
27 * @param duration Relative time to sleep
28 * @param pinned_thread If true (default), the final sub-millisecond busy-wait
29 * uses a CPU pause/yield hint (`HELIOS_PAUSE_CPU`), which keeps the calling
30 * thread runnable and holding its core the whole time => lowest wakeup
31 * latency, but only appropriate when the caller owns a dedicated core (e.g.
32 * a pinned render/simulation thread).
33 * If false, the tail loop instead calls `std::this_thread::yield()`,
34 * which relinquishes the thread's timeslice to the OS scheduler on each spin.
35 * Use this when the calling thread may share a core with other runnable work
36 * (e.g. a thread-pool worker), so this sleep doesn't starve unrelated threads
37 * of scheduler time.
38 */
39void PreciseSleep(std::chrono::nanoseconds duration, bool pinned_thread = true);
